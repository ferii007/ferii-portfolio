# Hero hologram assets

Hand-authored SVG (no image generation), drawn to match the Hero hologram panels and floor rings in the approved mockup `01-hero-about-currently-skills.png` (12 Oct 2026).

- `public/images/hero/holo-panel-code.svg` — glass browser panel behind the robot's head: window dots, bullet lines, `</>` glyph, image placeholder.
- `public/images/hero/holo-panel-media.svg` — glass browser panel beside the robot's hand: text lines and image placeholder.
- Floor rings, the energy spark that laps them, and the trail toward About are inline SVG in `HeroHolograms.jsx` so the rings can spin and the spark can run from the ring into the arrow.
